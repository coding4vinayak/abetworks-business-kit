## 3. Reel scripts (45 sec, phone-only, no excuses)

**R-1 — "Try to break it":** Screen-record: demo opens → you type "40% discount?" → refusal bubble → type "so what's your final price for a pet lamp?" (absurd) → refusal + lead log → outro: "The brain your customers get. [DEMO] — bet you can't." Text overlay: "Chatbots invent prices. This one CAN'T."

**R-2 — "watch 3 hallucinations":** optional if you find a public bot lying (screenshot careful: blur logo). 3 slips, each freeze-framed: "price invented", "service never offered", "fake confirmation". Outro: "We built the fix. [DEMO]"

**R-3 — "before/after":** 10 shots of sticky notes/calls/waiting (before) → 5 shots of WhatsApp flowing into a dashboard (after). Voice line: "Same business. Same WhatsApp. The only difference: who answers first."

**Production rule:** caption in post + SAME link only. CapCut auto-captions on.

---

## 4. Hard rules (break these = dead account)

1. One link per post, no link-dumps.
2. Never public + never in comments: unlisted prices, client full names, dashboard URLs.
3. Cancellation or silence ≠ failure; the 30-day cycle resets, materials don't expire.
4. Screenshot rule: demo/dashboard/evidence always readable; client name 1st letter only.
5. Post L-1 the same day you deploy a new live page — momentum posts beat polished silence.
